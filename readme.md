# 🎥 YouTube Downloader App

A modern and professional desktop-based YouTube video downloader built using **Python**, **Tkinter**, and **yt-dlp**.  
This application provides a sleek dark-themed user interface, fast video downloading, multithreading support, and a seamless user experience.

# ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/avnish-creator/youtube-downloader-app.git
```

Move into the project directory:

```bash
cd youtube-downloader-app
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python youtube_downloader.py
```

---

# 🧠 How It Works

1. Enter a YouTube video URL  
2. Select your download folder  
3. Click the **Download Video** button  
4. The app downloads the video using `yt-dlp`  
5. Download status and completion popup appear automatically
